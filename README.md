# Rental Management System - Backend

Backend API cho hệ thống quản lý phòng trọ được xây dựng bằng NestJS và PostgreSQL.

## Technologies

* NestJS
* TypeORM
* PostgreSQL
* JWT
* WebSocket
* Supabase Storage

## Features

* JWT Authentication
* Role-based Authorization
* RESTful API
* Invoice Cron Job
* Realtime Notification
* File Upload

## Run Project

```bash
npm install
npm run start:dev
```

## Environment Variables

```env
DATABASE_HOST=
JWT_SECRET=
SUPABASE_URL=
```
